# hanydaw-ms-plugins

A Claude Code plugin marketplace aggregating Microsoft's Power Platform and
Copilot Studio plugins:

- [microsoft/power-platform-skills](https://github.com/microsoft/power-platform-skills) —
  power-pages, model-apps, mcp-apps, canvas-apps, code-apps-preview,
  mobile-app, power-automate
- [microsoft/skills-for-copilot-studio](https://github.com/microsoft/skills-for-copilot-studio) —
  copilot-studio

## Usage

```
/plugin marketplace add HanyDaw/test
/plugin install power-pages@hanydaw-ms-plugins
/plugin install copilot-studio@hanydaw-ms-plugins
```

See [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json) for
the full plugin list.
